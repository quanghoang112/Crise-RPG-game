# Crise-RPG-game

## Introduction:
Crise is an upcoming 2D Action-RPG built from the ground up in Unity, combining classic top-down exploration with tight, responsive real-time combat and dynamic mechanics. Players will journey through a meticulously designed world, featuring an advanced item database system, unique interactable checkpoints, and a robust persistence layer that tracks every piece of gold and inventory item.

## The Passion Behind the Project:
This game is a labor of love born from my deep passion for game design and core loop engineering. For me, game development isn't just about making things move on a screen; it’s about crafting experiences, architecting clean, scalable systems under the hood, and solving the intricate puzzles of memory management, data architecture, and game logic. Every system in this project—from custom item serialization to smooth Coroutine-based visual transitions—has been carefully implemented to ensure a solid foundation.

## Future work:
While the core technical framework is locked down, the world of Crise is still in active development. I am currently ironing out a few remaining edge-case bugs to ensure absolute stability. Moving forward, I am excited to bring this world to life by introducing several major features, including:

- **Immersive NPC & Quest Systems**: Deepening the narrative and giving players meaningful goals.

- **Diverse Enemy Types**: Crafting unique AI behaviors to challenge player strategies.

- **Expanded Map Layouts**: Creating interconnected, atmospheric levels to explore.

This project represents my growth as a developer and my commitment to building seamless, immersive gameplay experiences from the source code up.
